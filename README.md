thẳng trong editor với project đã nạp sẵn, không cần tải file về.

## Ý nghĩa cột Extension

**☁️ cloud** — model đã train sẵn trên Machine Learning for Kids, mở link
là dùng được ngay.

**💾 local** — dữ liệu training nằm trong localStorage của từng trình
duyệt, không nằm trong file .sb3. Mở ở máy khác sẽ trắng dữ liệu, phải
nạp lại từ file CSV kèm theo rồi train.

**☁️ cloud · cần train 1 lần** — block AI và dữ liệu đã sẵn, nhưng model
chưa được train. Mở link, bấm *Train new machine learning model* một lần,
từ đó về sau mở là chạy.

**☁️ cloud · tự train khi bấm cờ** — trong dự án có block *train new
machine learning model*, nên bấm cờ xanh là máy tự tải dữ liệu và train
ngay trong trình duyệt. Không phải bấm gì trên Machine Learning for Kids,
chỉ cần chờ vài chục giây lần đầu.

**🧩 tự chứa · không cần train** — dùng cho các bài regression (dạng
predict number) vì loại này không có bản cloud thật trên ML4K. Dữ liệu
training + thuật toán (KNN, lazy learner) được nhúng thẳng vào 1 file
`.js` tự viết, host trên GitHub Pages, `extensionURLs` của file `.sb3`
trỏ sang đó thay vì bản gốc của ML4K. Mở link là chạy được ngay, không
cần train, không phụ thuộc IndexedDB của từng máy. Xem
[docs/share-predict-number-online.md](../docs/share-predict-number-online.md)
để biết cách làm cho bài mới cùng dạng.

Chi tiết từng project cloud, giới hạn của nền tảng và các việc còn phải
làm tay: xem [GHI-CHU-extension-mlforkids.md](GHI-CHU-extension-mlforkids.md).

## Cách link 1-click hoạt động

File `.sb3` host trên `raw.githubusercontent.com`, có header
`Access-Control-Allow-Origin: *` nên editor tải được qua CORS.
Editor đọc query param `?project=<url>` rồi tự tải và nạp project.

```
https://machinelearningforkids.co.uk/scratch/?project=<raw_url_da_encode>
```

Tính năng `?project=` do Dale Lane, tác giả Machine Learning for Kids,
bổ sung tháng 06/2026 theo đề nghị của KDI.

Tên file đặt theo ASCII kebab-case để URL không bị encode `%xx` rối mắt.
ML-M2.1 và ML-M3.1 dùng chung một số file, copy sang 2 thư mục để tách
theo cấp học.
